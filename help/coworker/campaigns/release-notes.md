# Adobe Co-worker Campaign發行說明 {#release-notes}

Co-worker Campaign版本會在持續傳遞模式上運作，允許以更可縮放、分階段的方法進行功能部署。

## 2026年7月 {#july-2026}

**發行日期： 2026年7月23日**

* 排程行銷活動，以立即傳送、在選定時間傳送或定期傳送
* 管理連絡人清單的取消訂閱清單，並在行銷活動電子郵件設定中設定取消訂閱引數
* 使用新的表單清查和編輯器建立和管理表單
* 憑證失敗時（包括更新現有連線時），聯結器設定會顯示更清楚的指引
* Marketo連線現在支援Experience Cloud URL
* 網域和寄件者精靈會在您的網域上線之前收到更多DNS記錄問題
* 直接從行銷活動輸入的新增功能表新增聯結器
* 清查頁面在沒有可顯示的內容時，會顯示以更友好的方式圖示的空白狀態
* 行銷活動深入分析會顯示每個量度的主要資料來源
* 品牌編輯器現在內建在入門中，以便進行更順暢的首次設定
* 在認可行銷活動之前預覽範例對象
* 同事行銷活動現在位於統一的Experience Cloud導覽殼層內
* 已移除清潔行銷活動展示板的浮動意見提示列
* 全方位的效能與可靠性提升功能

**發行日期： 2026年7月14日**

* 網域和寄件者推出、即時工作流程進度和真正的行銷活動深入分析
* 網域與寄件者設定現在已完整可用，而且您的寄件者選擇已自動儲存
* 從Campaign設定選擇或更新您的Campaign的電子郵件寄件者
* 即使在驗證網域之前，「寄件者」索引標籤仍可瀏覽
* 在交談期間新增的電子郵件草稿現在可靠地顯示在行銷活動展示板上
* 說明和意見回饋合併為一個簡化彈出視窗
* 開始新交談不再顯示最後一個交談的剩餘訊息
* 多圈對話不再在回應抽屜中顯示過時的提示
* 聊天訊息中的編號清單會維持其正確順序
* HubSpot聯結器設定現在會要求服務金鑰，以符合HubSpot自己的術語
* 試用版管理員表格會顯示使用者計數，且不再剪輯最後一列
* 全方位的效能與可靠性提升功能

**發行日期： 2026年7月9日**

* 維護橫幅和對話方塊現在會在排程的停機之前警告您
* 網域與寄件者具有引導式設定精靈，用於驗證網域及新增寄件者
* 行銷活動草稿現在會提示您先完成電子郵件和管道設定，然後再傳送
* 網域和傳送者驗證會攔截到更多問題，包括DNS記錄邊緣案例
* 設定檔功能表已移至側欄，以便更快速地存取
* Source PDF檔案現在會在品牌套件詳細資料中顯示為「丸子」
* 全方位的效能與可靠性提升功能

**發行日期： 2026年6月26日**

* 新的深入分析儀表板會顯示行銷活動績效KPI：傳送、開啟、點按、退回等
* 行銷活動在展示板上顯示即時狀態徽章，以便您一眼就能看到作用中的傳送
* 行銷活動面板中會顯示內容提示，引導您進行後續步驟

* 品牌檢色器可處理速記十六進位程式碼，並在整齊的彈出視窗中開啟
