# 排程行銷活動 {#schedule-campaign}

啟動行銷活動時，使用者現在可以選擇行銷活動的確切時間：立即、在特定的未來日期和時間，或重複（週期性）排程。 使用者也可以稍後再來，變更已啟動或排程的行銷活動排程。

> **變更內容**：之前，行銷活動只能立即啟動。 此版本新增一次性未來排程、週期性排程，以及啟動後編輯排程的功能。

## 先決條件

- 行銷活動必須準備好啟動（所有必要的設定完成）。
- 行銷活動處於可啟動狀態之外，不需要任何先決條件。

## 此功能的功能

當使用者啟動行銷活動時，他們會選擇三種排程模式之一，然後確認。 所選排程決定行銷活動何時開始傳送，以及對於週期性行銷活動，決定其重複頻率與結束時間（或是否結束）。 一旦行銷活動排程或上線後，即可從行銷活動設定編輯其排程。

### 關鍵行為

- 啟動時可以使用三種排程模式：**現在**、**排程一次**&#x200B;以及&#x200B;**週期性**。
- 未來排程的行銷活動會顯示「已排程」狀態，直到其開始時間為止，然後自動切換為「即時」。
- 已開始的循環行銷活動會顯示「即時」及其循環的摘要（例如「每週星期二上午9:00星期四」）。
- 循環行銷活動可以設定為無限期執行（「從不」結束）或直到特定結束日期。 單次和立即行銷活動沒有結束日期選項，因為它們只會執行一次。
- 使用者可以從行銷活動的設定，使用相同的排程選項，編輯已啟動或排程的行銷活動排程。

## 使用方式

**若要在啟動時排程行銷活動：**

1. 從行銷活動中，按一下&#x200B;**準備啟動**。
2. 在啟動對話方塊中，選擇排程選項：
   - **現在** — 行銷活動在啟動後立即開始傳送。
   - **排程一次** — 選擇未來的&#x200B;**開始日期** （日期與時間在一起）。
   - **週期性** — 選擇&#x200B;**頻率** （每日、每週或每月）和開始時間，然後設定週期模式（請參閱下列欄位）。
3. 如果選取「週期性」，請選擇行銷活動在日期&#x200B;**結束**&#x200B;永不&#x200B;**或**，並挑選結束日期（如適用）。
4. 確認使用選取的排程啟動行銷活動。

**若要編輯現有的排程：**

1. 開啟行銷活動，並前往其設定。
2. 尋找排程區段並選取目前的排程摘要。
3. 使用上述相同選項更新排程。
4. 儲存變更。

### 輸入欄位/引數

| 欄位 | 說明 | 必要? |
| --- | --- | --- |
| 排程模式 | 選擇「現在」、「排程一次」或「週期性」 | 是 |
| 開始日期 | 行銷活動開始的日期和時間（排程一次模式） | 是，排程一次 |
| 頻率 | 每日、每週或每月（循環模式） | 是，適用於週期性 |
| 開始時間 | 週期性行銷活動傳送的當日時間 | 是，適用於週期性 |
| 一週天數 | 行銷活動在哪一天重複 | 是，針對每週頻率 |
| 當月的第幾天 | 行銷活動在每月哪一天重複 | 是，針對每月頻率 |
| 結束行銷活動 | 從不，或是在特定的結束日期 | 是，適用於週期性 |

## 此功能沒有的作用

- 它不支援自訂重複間隔，例如「每2週」或「每3天」 — 只有標準的每日、每週或每月頻率可用。
- 它不支援相對的每月週期，例如「當月的第二個星期一」 — 每月只能使用特定的月日選擇。
- 它不提供&#x200B;**現在**&#x200B;或&#x200B;**排程一次**&#x200B;行銷活動的結束日期 — 只有在選取「循環」時才會提供結束日期，因為一次性行銷活動依定義執行一次。
