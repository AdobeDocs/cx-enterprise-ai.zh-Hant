# 透過同事聊天來檢查品牌合規性的內容

Co-worker可簡化行銷工作流程中品牌一致性的維護作業。 它可緊密整合，以根據既定的品牌准則評估內容。

例如，同事可以檢閱自動產生的內容（例如Instagram標題），確保內容符合您的品牌。 它會使用AEM治理功能和其他工具執行檢查，提供會醒目提示通過、失敗和不適用專案的結果。

同事不僅會找出問題，還會提供可操作的建議。 例如，如果註解過於普遍或缺少call to action，則會提供符合您品牌標準的修訂版本，並附上相關標籤。 此程式可簡化內容建立，並確保品牌合規性，而只需最少的心力。
