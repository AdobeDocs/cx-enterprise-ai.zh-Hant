# 如何從自然語言提示產生Adobe Journey Optimizer歷程

建立客戶歷程傳統上需要跨觸發器、時間規則、管道、決定邏輯和訊息步驟的廣泛設定。 在此影片中，您將會瞭解Co-worker如何透過將純語言說明轉換為Adobe Journey Optimizer中的完整草稿歷程來簡化程式。
 
透過自動化初始設定程式，團隊可以花更少的時間從頭開始建立歷程，而花更多時間改善客戶體驗和業務成果。
